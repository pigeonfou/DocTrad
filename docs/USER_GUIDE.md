# Guide utilisateur

Connexion avec un compte local → dépôt d’un document → choix automatique/profil/modèle présent → lancement. Le traitement est asynchrone et sa progression est actualisée automatiquement. Les fichiers appartiennent à leur propriétaire ; un autre compte ne peut pas les télécharger.

Relire les segments anglais/français et les alertes techniques/OCR. Corriger un passage puis enregistrer : une nouvelle exportation est mise en file. L’historique conserve l’ancienne valeur et la traduction IA initiale. Une correction sans alerte technique/OCR enrichit la mémoire privée de l’utilisateur pour une prochaine occurrence identique.

Le glossaire contient des correspondances exactes, sensibles à la casse, y compris des expressions composées. L’administrateur peut les modifier. La généralisation morphologique et la mémoire approximative ne sont pas implémentées.

DOCX : les images embarquées et tableaux restent dans le DOCX, mais les formats mixtes de caractères peuvent être simplifiés. PPTX : les diapositives sont réexportées. PDF : le résultat est recomposé en texte ; tableaux, illustrations et pagination originales ne sont pas reproduits. Les images et scans passent par OCR ; les annotations ne sont pas redessinées dans l’image originale. Vérifier le document avant diffusion.

Une erreur de modèle absent, de segment trop long ou de référence altérée n’est pas une traduction réussie. L’original reste stocké. La comparaison actuelle porte sur les segments textuels, pas sur une prévisualisation visuelle des deux documents.
